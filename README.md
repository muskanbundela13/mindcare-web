## 📖 About

MindCare is a full-featured mental health support web application built to make mental wellness accessible to everyone. It combines AI-powered chat support, mood tracking, educational resources, and emergency crisis tools into a single, compassionate platform.

---

## ✨ Features

| Module | Description |
|---|---|
| 🤖 **AI Support Chat** | 24/7 empathetic AI chatbot for emotional support |
| 📊 **Mood & Assessment** | Mood journaling and PHQ-9 depression screening |
| 📚 **Education Hub** | Learn about mental health conditions, symptoms & treatments |
| 👨‍⚕️ **Find a Doctor** | Browse and book consultations with verified specialists |
| 🆘 **Crisis Support** | Emergency helplines and personalised safety planning |
| 🌱 **Wellness Tools** | Guided meditation, breathing exercises, sleep & gratitude tools |
| 💬 **Community** | Peer support forums and shared experiences |

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm / yarn / pnpm / bun

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/mindcare.git
cd mindcare

# Install dependencies
npm install
```

### Running Locally

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
